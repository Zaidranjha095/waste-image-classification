Deep Learning semester project

Sort six kinds of waste from a single photo.

A MobileNetV2 classifier fine-tuned on TrashNet predicts cardboard, glass, metal, paper, plastic, or trash. The trained weights are public files, and this page runs the same network in the browser.

Student Name · Roll Number · Deep Learning

Problem

Material recovery depends on separating paper, plastic, glass, metal, and cardboard before they reach a landfill. Manual sorting is slow, and a single photo is enough information for a first automated guess.

This project trains a compact convolutional network for that six-way decision, saves the weights in a form an evaluator can download, and demonstrates predictions without a GPU server.

Method

  • Dataset: TrashNet (Thung and Yang, Stanford CS 229).
  • Architecture: torchvision MobileNetV2, ImageNet initialization, 6-class linear head.
  • Input: shorter side resized to 256, center crop 224, ImageNet mean and standard deviation.
  • Checkpoint: weights/model.pth with key state_dict.
  • Reference inference: python predict.py --image <path>.

Dataset and code

TrashNet contains photographs of a single object on a plain posterboard. The resized release used here has 512×384 JPEG images. The split is stratified, 70% train / 15% validation / 15% test, seed 42. The full image set is downloaded by download_dataset.py and is not stored in Git. One test image per class is kept in samples/.

Model demonstration

Loading the ONNX model…

Browser inference uses downloads/model.onnx, exported from the same checkpoint as weights/model.pth. Logits are softmaxed in the page. Preprocessing follows torchvision: shorter side 256, center crop 224, ImageNet normalization.

Load the PyTorch checkpoint

import torch
from model import build_model

checkpoint = torch.load("weights/model.pth", map_location="cpu", weights_only=False)
model = build_model(num_classes=len(checkpoint["classes"]), pretrained=False)
model.load_state_dict(checkpoint["state_dict"])
model.eval()

# Or, from a shell:
# python predict.py --image samples/paper.jpg

Educational project. The photos in TrashNet use a plain background, and the model is not a system for handling hazardous waste.
